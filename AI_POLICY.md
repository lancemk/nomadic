# AI Contribution Policy

`nomadic` allows AI-assisted work, but not AI-owned contributions.

## Allowed

AI tools may assist with:

- drafting code, docs, or tests
- summarizing repository context
- suggesting refactors or debugging paths
- improving wording, structure, or clarity

## Required Human Ownership

For every contribution:

- a human must understand the full change before submission
- a human must verify the behavior or meaningfully review the verification
- a human must be able to explain and defend the implementation choices
- a human must remain responsible for follow-up fixes and review responses

## Not Accepted

The following are not acceptable for merge:

- pull requests submitted as purely autonomous agent output
- changes the submitter cannot explain or validate
- AI-generated code or docs pasted in without human review
- attempts to use AI disclosure as a substitute for testing or understanding

## Disclosure

Contributors must disclose meaningful AI assistance in the pull request template, including the tools used and the extent of assistance.

## Maintainer Discretion

Maintainers may ask contributors to revise, reduce, or withdraw AI-assisted changes if authorship, quality, provenance, or reviewability is unclear.
